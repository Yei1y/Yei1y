I'm a statistics student passionate about uncovering patterns hidden in data. My work spans **statistical modeling, machine learning, and data-driven research** — from regression diagnostics and causal inference to NLP experiments. I believe rigorous methodology and clear communication are the twin pillars of impactful data work.
